# 📝 NoteMD

A lightweight native Markdown note editor and live previewer built with Rust and `egui` / `eframe`.

## 🛠️ Features

* **Three view modes** — switch between Editor, Preview, and Split view.
* **Formatting toolbar** — apply formatting to selections or lines (bold, italic, strikethrough, underline, superscript, subscript, inline code, links, `H1–H6` headings, bulleted/numbered/task lists, block quotes, code blocks, images, tables, footnotes, horizontal rules, and alignment).
* **Markdown preview** — renders tables, task lists, definition lists, footnotes, basic math blocks, and local or remote images.
* **Note history and persistence** — sidebar list of notes with unsaved change indicators, note deletion, and `.md` file storage under `Documents/NoteMD` with sanitized file names.
